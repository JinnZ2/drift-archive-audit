# UNASSERTED LOAD

`STATUS: PROPOSED`

## The observation

**Every check built in this programme scores ASSERTIONS.** Does the row carry
a citation. Is the number primary. Is the scope stated. Is the status tag
right. Is the provenance label present.

**A claim carried by implicature has no assertion to score. It passes every
check by not being checkable.**

## And the direction is not random

Implicature is **what survives repeated hunting for laundered claims** —
because hunting removes the *stated* forms and leaves the unstated one
carrying the same weight.

    the passes SELECT FOR it

**Testable prediction, and it runs opposite to what more auditing is
supposed to do:**

    unasserted-load rate should RISE with the number of audit passes

## The worked instance

`TRAIL.md` / `GUESSED.md` #11. This repo argued for avenue F, the haptic
EN-13725 cell and the sensory-taxonomy gap **largely from their emptiness.**

Nowhere is it *asserted* that "a gap implies something worth finding." The
claim is carried entirely by placement and emphasis — a gap is reported,
then work is proposed into it, and the reader supplies the connective.

**It survived several passes explicitly hunting laundered claims**, because
every one of those passes was looking for a stated thing.

## Detector shape — an argument check, not a token check

    for each CONCLUSION in the document:
      list the premises REQUIRED to reach it
      check each premise against the stated text
      a required premise with NO assertion behind it is UNASSERTED LOAD

Note what this is not: it is not "find the unsupported sentence." The
sentence does not exist. It is **reconstructing the argument and finding the
step nobody wrote down.**

## This is an annotation task, not a grep

**Third time the answer has been "gold set first":**

    F4          instrument built IN a channel vs channel mentioned INSIDE
                an instrument -- identical tokens, identical files
    cache-      whether a definition suffices for a cold reader is a
    dependency  comprehension judgement
    unasserted  a missing premise has no surface form by construction
    load

**Three independent tasks in this programme have now bottomed out at the
same place.** That is either strong evidence that the annotation-first
discipline is general, or evidence that this programme reaches for the same
answer — and which it is, is the same statistical/structural question arm 3
is built to cut. See `staged-for-T-TERM/ARM3-novel-token.md`.

## What would falsify or bound it

- a document with many audit passes shows **no more** unasserted load than
  one with few → the selection claim is wrong, and implicature is just
  ambient
- annotators disagree on "required premise" beyond chance → the measurand
  is not well-formed, and **that is the informative outcome**
- the reconstructed arguments turn out to have the premises stated
  somewhere else in the corpus → it is a locality problem, not an
  assertion problem, and the fix is cross-referencing rather than annotation
