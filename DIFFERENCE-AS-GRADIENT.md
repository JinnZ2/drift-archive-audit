## 2. THE RECURSION, AND IT LANDS ON THIS RECORD TOO

One statement, rendered four different ways across a year: **substrate ·
culture · programming · "the differences."** A lexical search under-counts
it **because of the difference the statement is about** — shape-stored
content measured by a label-side tool.

**`HARVEST.md` is that tool.** Its twelve patterns are literal strings. Run
against a body of work whose central claim is that the same shape surfaces
under different words, they return a floor by construction, and the
amendment's two disagreeing samples are the same defect one level up.

    the statement    the same thing shows up worded differently each time
    the instrument   counts words
    the result       an undercount whose SIZE is unknown, not small

That is not a fixable bug in the regex. A label-side tool cannot measure
label-independence. **Registered, not built:** the measurement this needs is
shape-side — cluster by relation, not by token — and nothing in this repo
does that.
