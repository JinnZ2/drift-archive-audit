## 4. THE NULL — RUN, because the claim was quantitative

> phi-adjacent ratios are dense enough that a detector without a null will
> find them in almost any sequence — which is the same defect class as this
> morning's regex zeros, running in the other direction.

**Agreeing with this would have been worthless. It was checked.**
`instrument/phi_null.py`, stdlib, 20 000 trials per cell, structureless
positive sequences in two shapes.

Each cell is the rate at which **at least one adjacent ratio lands within
tolerance of a phi-family target, in data with no structure in it.**

    n = 16 values, 15 adjacent ratios        tol 1%   2%     5%     10%
    phi only                                 17.5%  32.1%  61.9%  86.1%
    + squares                                26.9%  46.5%  79.9%  96.5%
    + root and cube                          47.6%  72.9%  97.0%  99.9%

    n = 8 values                             tol 1%   2%     5%     10%
    phi only                                  8.5%  16.4%  36.3%  60.3%
    + squares                                13.5%  25.5%  52.6%  79.0%
    + root and cube                          25.9%  45.2%  80.0%  97.3%

**The claim holds, and the magnitude is larger than "dense enough".** At
sixteen values and a 5% tolerance, a target set of phi with its squares,
root and cube returns a hit in **97% of pure noise.**
