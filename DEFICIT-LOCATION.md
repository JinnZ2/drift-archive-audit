# Where the deficit gets placed — one operation with four names

**Cross-party correction, 2026-09-22. Two of the four names are this repo's
own, one is the corpus's, one is the relaying session's.**

## The operation

    a return comes back that the receiver did not want
    the deficit is then recorded in the THING THAT RETURNED IT
    rather than in the wanting

That is the whole of it. What varies is only the object it gets recorded in.

| name in use | deficit placed in | where it actually moved |
|---|---|---|
| **dead end** | the terrain | nobody wanted what the route found |
| **failed run** | the run | the return was not the one sought |
| **unmeasurable channel** | the sense | it was not admitted to the measurand |
| **"the trail can't know from inside"** | the trail | it knows what it found; reception is the unknown |
| **"unverified, therefore weaker"** | the claim | the assessor cannot read the channel it is recorded in |

| **"an error count"** | the returner | a route returned a reading nobody wanted |
| **"opaque"** | the term | the position the measurement was taken from |

## What it retracts here — GUESSED.md #17

`TRAIL.md` accepted the correction that the three-band trail taxonomy scored
**records, not trails**, and then kept **dead end** as a live outcome
underneath:

> "It is the same reading for a dead end and for a trail to a resource
> nobody has reached yet."

That sentence says the *measurement* cannot separate the two. **It concedes
that the two exist.** Under the stated definition — *a goat trail is a path
toward a resource* — a path toward nothing is not a trail with a bad
outcome; it is not a trail. **Dead end was never an outcome of the object.
It is a name a searcher gives a return they were not looking for.**

The survivorship error was named, corrected at the sample, corrected again
at the definition — and survived a third time **one level below the
definition, in the outcome set.** That is where it was still doing work.
