# Declined reads — the register that makes a gate visible

**Why this file exists.** A gate produces the same output as having no term
to search with: **nothing found.** Downstream the two are indistinguishable,
which is `ABSENCE.md`'s central hole with this audit's own procedure as the
cause. `GUESSED.md` #30.

**This register is the fix, and it is a required field rather than a note.**

    A gate may block SCORING. It may not block READING.

    If a read is declined, it is logged HERE, at the moment of declining
    and not afterwards.

    NO ABSENCE IS REPORTABLE FROM THIS REPO WITHOUT THIS REGISTER
    CHECKED FIRST.

An absence claim that has not checked this file is an unmarked assertion —
the same defect `EVIDENTIALITY.md` row 5 describes, where a channel that does
not require the provenance field simply drops it.

## TWO KINDS OF DECLINE, and the register's job is to keep them apart

    PROCEDURAL   a gate, a scope rule, a not-selected. Produces an empty
                 hand for reasons unrelated to the material.
                 -> Shadow-Hunting. It cost a find.
                 -> AI-Consciousness-Sensors, JinnZ2/JinnZ2. Both read
                    one turn after this register existed.

    PRINCIPLED   reading the thing DESTROYS the measurement.
                 -> gate_log.md. Reading it burns C-7's reference gate.
                 -> This one is correct and stays.

**Both look identical downstream — nothing found.** The register is the only
thing that separates a decline that should be reversed from one that must
not be.

**Three of the four procedural declines here were reversed within a day of
being logged.** The principled one has not moved and should not.

## The inconsistency this register exists to prevent

At the moment the Shadow-Hunting gate was written, **eight non-pilot
repositories were already cloned and readable in this session** —
`Noise-as-Information-Sensor`, `ai-human-audit-protocol`,
`Rosetta-Shape-Core`, `tool-off-metrology`, `DIY-CNC`,
`Prosthetic-arm-CNC`, `Resilience-hydrology-core`,
`The-Curriculum-of-Everything-Earth-`.

**The gate was applied to none of them.** It was applied to exactly one repo:
the one being discussed. The fixture-versus-audit distinction that later
resolved it was available throughout and was not stated until the URL
arrived.

**A correctly-worded gate, inconsistently applied, in the direction of not
looking.** The register makes that visible at the moment it happens instead
of two hours later.

## What counts as a decline

    a repo not cloned                   -> log it
    a file not opened after being named -> log it
    a search not run after being
      specified                         -> log it

    a slot left empty rather than
      reconstructed                     -> NOT here. That is the
                                           empty-slot rule in
                                           GLOSSARY.md, and it is a
                                           DIFFERENT operation: refusing
                                           to fill, versus refusing to
                                           look.

**Do not merge those two.** One protects the record from invention; this one
protects it from a procedure that returns an empty hand and looks like a
finding.

## Standing consequence

**The pilot gate is narrowed, with effect from now:**

    it gates SCORING -- no A2 hash, no score, no verdict, no entry in
                        any result table
    it does NOT gate READING -- a repo may be opened as a control
                        fixture at any time, and the fixture use is
                        stated where it happens

`SHADOW-HUNTING.md` §6 and `ENUM-SWEEP.md` already carry the distinction.
**Both were written after the prompt, not before.** That is why it is a rule
here rather than a paragraph there.
