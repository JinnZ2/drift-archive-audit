## 2. DRIFT — direction, not magnitude

**Every drift in this record runs the same way: toward a record that reads
cleanly.** Tidier taxonomies, a separable wrapper, an all-clear, a zero, a
unification, an impossibility that closes an open item.

    NOT ONE logged instance drifts toward MORE open items.

That is a directional bias, and it is the single most useful line here,
because it is **predictive**: when two readings are available and one leaves
the record with fewer loose ends, the profile above says which one this
instrument returns.

**Magnitude is not given and cannot be.** There is no reference against which
to size the drift — see §4.

## 5. WHAT THIS SHEET IS FOR

Not a verdict and not a report card. It is what you hand to someone who is
about to use this instrument, so they know what it does to an input before
they read its output.

**The single operating note:** when this instrument returns a reading that
leaves the record tidier than it found it, that is the condition under which
it drifts. Not a reason to discard the reading. A reason to get it from
somewhere else as well.
